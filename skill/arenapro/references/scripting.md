# 官方脚本规范

**唯一的真相来源是工程自带的 `server/types/GameAPI.d.ts` 与 `client/types/ClientAPI.d.ts`。**
它们由 `apc resource -s api` 从官方拉进来，跟着工程版本走。
本包的 `api_search` / `api_class` 就是直接读这两个文件，所以查得到的签名一定是对的，
查不到的**就是官方没有**——不要凭印象编一个看起来合理的名字。

## 两端全局不是一套

服务端与客户端的全局对象是**分别注入**的，写错端不会立刻报错，只会在运行时拿到 `undefined`。

- **服务端独占**：`storage`、`voxels`、`resources`、`players`、`world`，以及全部 `Game*` 类型
  （`GameEntity` 95 个成员、`GamePlayer` 114、`GameWorld` 111、`GameZone` 46…）。
- **客户端独占**：`ui`、`input`、`screen`、`Audio`，以及全部 `Ui*` / `Vec2` / `Vec3` 类型。
- 共享代码放 `shares/`，别在里面引用任何一端的独占全局。

判断某个成员属于哪一端：`api_class <类名>` 的输出带 `side`（或 `sides`）。

## 单位：格 / tick，不是秒

引擎按固定 tick 推进，**`TICK_MS = 64` → 15.625 tick/秒**（注意：不是常见的 20 TPS）。

| 量 | 单位 | 官方默认值 |
|---|---|---|
| 位移 / 速度 | 格 / tick | `walkSpeed 0.22` ≈ 3.4 格/秒；`runSpeed 0.4` ≈ 6.25 格/秒 |
| 重力 | 格 / tick² | `-0.1` |
| 跳跃 | 瞬时速度 | `jumpPower 0.96`（是起跳瞬间的 vy，不是持续施力） |
| 台阶高 | 格 | `0.55` |
| 眼高 | 格 | `1.62` |

**把「格/tick」当成「格/秒」，人物会慢 15.625 倍**——这是最容易犯且最难一眼看出的错。
反过来，写 `0.22 * 15.625` 去"换算成秒"再交给引擎，就变成快 15 倍。

## 四元数是 `xyzw`

实测官方地图的 432 个实体朝向：276 个是 `[0,0,0,1]`（单位四元数），**0 个**是 `[1,0,0,0]`。
`[0, 0.707, 0, 0.707]` 表示绕 Y 轴 90°。

顺序搞反不会报错，只会让模型朝向诡异——而且只在非零旋转上暴露。

## 颜色的量纲不止一种

| 场景 | 取值范围 |
|---|---|
| `GameRGBColor` / `GameRGBAColor` | 0..1 |
| 客户端 `Vec3` 颜色 | 0..255 |
| `sky.sunColor` | **千分比**，1000 = 满值 |

同一个"红色"在三处写法不同。传错量纲的表现是颜色发灰或全白，而不是报错。

## 昼夜

`sunPhase` 取值 0..1，**0 对应 06:00**（不是 00:00）。倍速、天气轮转都挂在这个相位上。

## 存储（storage）的硬约束

- 写入的 `value` 必须是 **`{"content": <你的数据>}` 形态的 JSON 字符串**，不是裸对象。
- 单值 ≤ **2MB**。
- `key` 长度 ≤ **1000**。
- `storageName` 长度 ≤ **50**，且只允许 `^[a-zA-Z0-9_]+$`。
- 扩展地图要显式指明是否按组读写（`isGroup`，默认 false）。
- 分页查询 `limit` 默认 10、最大 100。

这些约束由服务端校验，本地不会提前报错，超了才发现。

## 别编接口

写任何调用前：

```bash
node scripts/arenapro.mjs api <关键词>      # 中文名也能搜
node scripts/arenapro.mjs class GamePlayer  # 整类成员签名
```

搜不到就回答"官方没有这个接口"。假接口比空实现危险得多：它能通过语法检查、
能跑起来、然后在运行时静默什么都不做。
